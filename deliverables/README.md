The public package omits uploaded RETRO responses, original workbook, pasted conversations and environment/credential files. Derived results and the already-public processed input are included. To recompute RETRO or workbook extraction, supply your own original files locally; the source aliases and commands are documented in the package. The full local bundle remains in the cloud workspace.

The current study is exploratory. Summer/SMR courses are excluded; causal effects are not established. Remaining-work arithmetic is tested, but real historical remaining-work models require the missing grade exports/availability history. All 14 tests passed in the packaged public project.
